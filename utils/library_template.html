Building the library

  1. Find the paper with the search links on each reference.
  2. Save the PDF into the same folder as this page under the suggested filename, or paste the URL of the PDF into Source URL and it is downloaded for you.
  3. If a paper can't be found, use Mark unavailable. Availability updates when you come back to this tab; filter to Still to find to see what is left.

This page is opened from disk, so availability is as of the last build and URLs can't be saved. Run uv run utils/library.py serve and open the link it prints to check the folder live and download from URLs.
